# 羊供应链管理系统（Mutton Supply Chain MS）

活羊采购 → 暂养 → 养殖 → 屠宰 → 出库 → 门店 → 应收 / 应付，一条链路的本地台账系统。
桌面端 PySide6，数据存本地 JSON，出表按《账表记录-羊.xlsx》的七张台账版式。

- **定位**：一个人（或一家店）就能用起来的供应链台账，不依赖服务器、不需要账号
- **原则**：台账只存原始事实（日期、批次、只数、kg、单价），金额 / 结存 / 出肉率 / 库存 / 差异**全部现算**
- **客户口径**：富民锐泽农业科技有限公司　·　默认门店「关一店」

## 一、快速开始

```
# 1. 建虚拟环境（只需一次）
python -m venv .venv
.venv\Scripts\python -m pip install -i https://mirrors.aliyun.com/pypi/simple/ -e .

# 2. 启动
运行.bat
```

命令行启动（不建快捷方式时）：

```
set PYTHONPATH=src
.venv\Scripts\python -m mscm
```

首次打开会自动建账：补门店档案（关一店）与商品档案，并灌一套**能对上账**的
示例数据（2 个批次 / 5 张屠宰单 / 门店入库·销售·盘点），方便先看效果再清空。

> 清空示例：`更多 → 系统设置 → 清空全部台账`（保留门店与商品档案）。
> 数据文件：`data/mscm.mscm.json`，整份就是一个 JSON，拷走即备份。

## 二、模块与页面

### 经营分析

| 页面 | 内容 |
|---|---|
| 经营概览 | 暂养存栏 / 结存、门店账面库存、本月屠宰与销售、本月毛利（简化口径）；批次结存表 + 门店库存表 |
| 数据校验 | 七张台账之间的勾稽逐条核，结论分「通过 / 注意 / 异常」，可导出校验表 |

### 档案

| 页面 | 内容 |
|---|---|
| 商品档案 | 白条 / 分割品 / 副产品；屠宰产出、门店商品的名称底表 |
| 门店档案 | **加一家门店，左侧「门店管理」下就多一个节点**，节点固定挂六项：损益报表 / 进销存台账 / 入库台账 / 销售台账 / 结存/盘点台账 / 应收款项 |
| 客户名录 | 版式与表头照《客户名录.xlsx》：序号 / 归属 / 客户名称 / 统一信用代码或身份证号 / 联系人 / 联系电话 / 经营·配送地址 / 结算方式 / 首次供货时间 / 业务对接人 / 备注；「导出名录」直接出同版式的 Excel（含结算方式下拉） |

### 活羊采购 & 屠宰

| 页面 | 内容 | 关键口径 |
|---|---|---|
| 活羊入库&结余 | **行内录入**（界面同「养殖记录」）：序号 / **入库日期（首列）** / 批次编号 / 品类 / 圈号 / 供应商 / 标识 / 入栏只数 · kg · 均价 / 入栏金额 / **当前存栏 / 暂养结存** / 备注；序号「＋」插一批、双击就地改、操作列只有一枚多功能集 | **编号＝入库日期**：2026-11-15 → `20261115`，同日第二批 `20261115-2`；这里是入库数据的唯一来源；入栏金额（kg × 均价）同时自动提取成一张应付单；存栏取养殖记录期末、结存取暂养台账累计入 − 累计出 |
| 屠宰场暂养出入库台账 | 批次 × 日期：**两行式表头**（入库 / 出库 / 结余）；入库行取自批次（日期、圈号、标识、供应商、只数、kg、单价全只读）→ 出库（用途 / 只数 / kg）→ 结余 | 每批自动一行入库行；入库金额 = kg × 单价；**出库金额按该批次累计入库加权平均单价**；结存 = 累计入 − 累计出 |
| 养殖记录 | 期初存栏 − 出栏 = 期末存栏；投料（原材料 / 单位 / 数量 / 单价 / 金额） | 期初自动接上一行期末，批次首行取批次档案入栏只数 |
| 屠宰记录 | 一张屠宰单（领入只数 / 毛重 / 标识 / 屠宰人）+ 多条产出明细 | 出肉率 = 产出 kg ÷ 领入毛重；领用成本 = 毛重 × 批次加权均价；单位成本 = 领用成本 ÷ 产出 kg |
| 屠宰出库明细 | 出库/销售日期 · 羊群批次（入库时定的那个批次）· **销售批次** · 去向 · 商品 · 数量 · 单价 · 金额 | 金额 = kg × 单价；**销售批次 = 类型编码 + 销售日期**（对外销售 `T`、内部调拨 `N`，如 `T20261115`），改日期或去向自动重算；「→ 转门店入库」把调拨单幂等转成门店入库 |
| 应收款项 · 屠宰销售 | 两张表：应收款（含逐笔收款）/ 未收款 | 屠宰场直接对外销售挂的账：**出库单收款方式＝挂账 / 月结 自动提取**成应收单；结算方式取自客户名录，**约定收款日 = 销售日期 + 账期**（现结 / 预付 0、周结 7、半月结 15、月结 30 天）；收款照银行流水**逐笔挂在应收单下面**（一张单可多笔，应收单那行的「已收金额 / 抹零金额」是下面各笔的**小计**）；**未收 = 应收 − 已收 − 抹零**，正值是未收、**负值是预收**，带账龄与逾期；未收款表按客户出一张 **A4 纵向对账单**（版式照《账表记录-羊》的「对账单2」：逐笔未收 + 合计 + 人民币大写 + 双签章区） |
| 应付款项 · 活羊采购与付款 | 两张表：应付款（含逐笔付款）/ 未付款 | 活羊采购与付款，方向反过来：**「活羊入库&结余」一次采购自动提取一张应付单**（应付金额 = 入栏 kg × 入栏均价；供应商电话取批次上原来填的，批次页不再摆电话列，可在应付页手填）；表头照《账表记录-羊》的「应付款」——序号 / 入库批次 / 供应商名称 / 联系电话 / 商品 / 应付金额 / 付款日期 / 已付款金额 / 未付款余额；付款照银行流水**逐笔挂在应付单下面**（应付单那行的「已付款金额」是下面各笔的**小计**）；**未付 = 应付 − 已付**，负值是预付 / 多付，带账龄；未付款表按供应商出一张 **A4 采购对账单**（同一套模板版式，签章区换成「采购方 / 供应商确认」） |

### 门店管理 › 关一店

| 报表 / 台账 | 内容 | 关键口径 |
|---|---|---|
| 损益报表 | 纵向项目表：一 产出/收入 → 二 投入/成本 → 三 产投/损益 → 六 盈利指标（损益率 / 单位收入 / 单位投入 / 损益÷投入 / 单位损益），表身只有「序号 / 项目 / 数量 / 金额」 | 产出 = 当日销售台账金额；投入 = 当日出库成本；**损益 = 产出 − 投入**；按一级明细（白条 / 分割品 / 副产品）归集，正为益（红）、负为损（绿）；页脚自动勾稽「销售台账 − 本表产出 = 0.00」 |
| 进销存台账 | 一级明细 × 二级明细，六段「数量 / 金额」：上日结余 / 当日入库 / 当日出库 / 当日结余 / 当日销售 / 当日损益；表尾「小计」行 | **出库 = 上日结余 + 当日入库 − 当日结余**（出库不单独录，倒算）；当天记了盘点的商品结余取实盘，没记盘点的取账面（不会因为漏盘把出库算大）；**损益 = 当日销售 − 当日出库**；可按一级 / 二级明细筛选、导出 |
| 入库台账 | 来源（屠宰场调拨 / 外购 / 退库）、批次、商品、只数、kg、单价 | 金额 = kg × 单价；调拨来的行备注带来源出库单号 |
| 销售台账 | 去向、批次、商品、只数、kg、单价、应收、实收、收款方式、客户 | **应收 = kg × 单价**；实收自动跟应收，改动即见未收金额 |
| 结存/盘点台账 | 盘点日期、批次、存放地点、商品、库存只数 / kg、单价 | 可「按账面生成」草稿行（入库 − 销售），再改实盘数；是进销存台账「当日结余」的取数来源 |
| 应收款项 | 两张表：应收款（含逐笔收款）/ 未收款 | 门店对外销售挂的账：销售单「应收 > 实收」的差额自动提取成应收单；收款照银行流水逐笔挂在单下（应收单行显示已收 / 抹零小计）；未收 = 应收 − 已收 − 抹零，负值即预收；未收款可按客户出对账单 |

## 三、勾稽关系（系统自动核，校验页逐条列）

```
暂养结存只数 = Σ入库只数 − Σ出库只数            （按批次累计）
养殖期末存栏 = 期初存栏 − 出栏只数
屠宰出肉率   = 产出合计 kg ÷ 领入毛重 kg          （整羊一般 35%~55%，超出提示核对）
领用成本     = 领入毛重 kg × 批次累计入库加权平均单价
门店账面库存 = Σ门店入库 kg − Σ门店销售 kg        （按 门店 × 批次 × 商品）
门店当日出库 = 上日结余 + 当日入库 − 当日结存      （当日结存有盘点取实盘，没盘点取账面）
门店当日损益 = 当日销售 − 当日出库
盘点差异     = 实盘 kg − 账面 kg
未收款余额   = Σ应收款 − Σ已收款                  （收款逐笔挂在应收单上；没挂单的老数据按客户 FIFO）
未付款余额   = Σ应付款 − Σ已付款                  （付款逐笔挂在应付单上；负值即预付 / 多付）
本月毛利     = (门店销售 + 屠宰直销) − 已售商品成本（调拨不计收入，成本按批次加权平均）
```

数据校验页覆盖：批次结存为负、暂养出库超入库、养殖出栏超存栏、屠宰单缺产出、
出肉率异常、屠宰出库超产出、门店库存为负、销售未收（挂账发生额）、盘点与账面差异、
应收款项未收余额、收款超过应收（预收）、应收单来源销售单已删、
应付款项未付余额、付款超过应付（预付 / 多付）、应付单来源批次已删。

## 四、操作习惯

- **插一行**：鼠标移到序号上，左下角冒出「＋」，点它就在**这一行下面**插一行空白（浅黄底）；
  筛选条上的「＋ 新增」则插在最上面
- **就地改账**：双击一行（或任意单元格）进编辑；改完**点别处就自动保存**——换行、换页、点空白、
  点序号、点工具栏都算，不用去找保存键；按 Esc 放弃本次改动，回车也算收工
- **入库不在这里录**：暂养台账的入库行由「活羊入库&结余」自动生成，供应商 / 只数 / kg / 单价灰底只读；
  要改进价就去「活羊入库&结余」改，改完台账跟着变。缺入库行时点筛选条上的「从批次补入库」
- **填不完不挡路**：离开本行时内容不合法——新行原样搁成黄色草稿（双击继续填），
  老行还原成库里的内容，界面不会卡在编辑态
- **行尾一枚图标**：四宫格＝多功能集（删除本行）；编辑不占位置，双击一行或单元格即可。
  **操作列冻结在表格最右边**，暂养台账横向滚到哪一列它都在
- **保存 / 撤消 / 恢复**：在页面抬头（台账名 + 「填写说明」右侧）的三个小图标，照 WPS 画法；
  管的是当前这张台账，保存可 Ctrl+S。概览、校验这类没有账可存的页面会自动收起这一组
- **删错了**：点顶部「撤消」，删掉的行原样回来；恢复＝把撤消掉的动作再做一遍（留 50 步）
- **排序 / 筛选**：点表头右侧的小三角 → 升序 / 降序 / 只看某一个值（日期、羊群批次最常用）；
  排过序列头显 ▲▼，筛过值显金色漏斗
- **右键菜单**：表格任意一行右键，同样能编辑 / 删除 / 撤消 / 恢复
- **填写说明**：页面抬头右侧「填写说明」，展开本页每一列的口径
- **期间**：默认「本月 1 日 → 业务日期」；抬头业务日期改动后，各页期间跟着跳到该月
- **转门店入库**：屠宰出库页的「→ 转门店入库」，已转过的自动跳过，可反复点
- **按账面生成**：门店「结存/盘点台账」的「按账面生成」，先拉账面数当草稿，再改实盘
- **门店两张报表**：左侧「门店管理 › 关一店」下的「损益报表」「进销存台账」；日期只认页面抬头的业务日期，
  「进销存台账」可按一级 / 二级明细筛选，两张表都能直接导出 Excel
- **应收款项**：应收单自动提取（进页面就同步一次，销售单改了跟着变），双击就地改；
  记收款：点应收单右侧「多功能集 › 记一笔收款」，或点已有**收款行**前面的「＋」再加一笔，
  收款日期 / 已收金额 / 抹零金额照银行流水填（到账取整抹掉的零头填在抹零），未收金额自动往下减；应收单那行显示下面几笔的小计；未收 = 应收 − 已收 − 抹零，正值未收、负值预收（绿字）；未收款只读；「导出应收+未收」一次出两个工作表；「生成对账单」选客户、手填客户与我司各一组联系人和电话，即按模板「对账单2」出 A4 纵向一页
- **应付款项**：应付单按活羊入库&结余自动提取（进页面同步一次，批次改了进价 / 供应商 / 日期跟着变），
  入库批次与应付金额灰底只读；记付款：点应付单右侧「多功能集 › 记一笔付款」，或点已有**付款行**前面的「＋」再加一笔，
  付款日期 / 已付款金额照银行流水填，未付自动往下减；未付 = 应付 − 已付，负值即预付 / 多付（绿字）；
  未付款只读，按账龄排序、可勾「只看账龄 30 天以上」；「生成采购对账单」选供应商、手填供应商与我司各一组联系人和电话，
  按模板「对账单2」出 A4 纵向一页（签章区是「采购方 / 供应商确认」）
- **导出**：单张台账按筛选导出；`系统设置 → 导出整套台账` 一次出七个工作表（应收、应付款项在各自页面单独出）

```
└─ 账表记录-羊.xlsx          客户提供的空账表模板（只作口径参照，程序不写它）
```

## 六、设计取舍

1. **JSON 账套，不用数据库**：单人使用、数据量小、便于拷走与版本比对；整份原子落盘，不写坏原文件。
2. **派生数字不落库**：改一行原始数据，所有结存 / 库存 / 差异自动跟着变，不会出现两套数打架。
   **入库也只有一份**：暂养台账的入库行从「活羊入库&结余」生成（`repo.sync_feed_inbound`），
   批次一改就同步，不会出现"档案一个进价、台账另一个进价"。
3. **行内录入为主，弹窗为辅**：平铺台账就地改（对着上下行改更不容易错）；屠宰单是「单据 + 分录」，
   用对话框一次改完头和明细。
4. **门店锁定**：从「关一店」进去的台账不允许改门店，避免单据串店。
5. **调拨贯通**：屠宰出库的门店调拨单可一键生成门店入库，靠 `link_id` 保证幂等，不重复入库。
6. **操作列冻结**：六张台账的「操作」不放表格里，而是并排放一列自绘的小面板，行位置按表格视口实时对位
   （`ui/pages/base_ledger.py` 的 `OpsStrip`）。这样暂养 17 列横向滚到哪，删除 / 编辑都在右手边。
7. **没有保存键**：改完点别处就落库，靠编辑框的焦点离开事件触发；校验不过就不落库、本行保持编辑态，
   不拿"保存失败"把人的输入吞掉。要反悔用「撤消」（页面级历史栈，50 步）。
