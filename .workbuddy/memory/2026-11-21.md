### 2. 操作列冻结在最右，只留两枚图标
- 铅笔＝编辑本行（双击一行/单元格同样就地编辑）；四宫格＝多功能集（删除 / 撤消 / 恢复）

### 3. 离开即存（不再有保存/取消按钮）
- 编辑框装 `eventFilter` 盯 `QEvent.FocusOut` → 点其他任何位置（换行、换页、点空白）即落库
- 空草稿自动丢弃，不拿校验错误烦人；校验不过则提示并保留编辑态（数据不丢）
- `refresh()` 开头先 `_commit_edit()`：避免刷新把没存的改动冲掉（校验不过就本次不刷新）
- 纯文本/数字框回车＝收工；Esc＝放弃本次改动

### 4. 撤消 / 恢复
- 页面级历史栈（50 步），命令三种：insert / update / delete（存 before/after 快照，走子类 save_record/delete_record，表结构无关）
- 删除后提示「点多功能集 › 撤消可以捡回来」

## 踩过的坑（下次别再踩）
1. `QAbstractScrollArea.setViewportMargins()` 对 QTableWidget **无效**，viewport 几何不变 → 改不进去
2. `mapTo` 在布局未落定时返回离谱值（要 (1,36) 给 (273,233)）→ 用 `viewport().geometry().top()`
3. `QIcon(QPixmap)` **不吃 devicePixelRatio**：设了 dpr 会把图标当 96px 用，只剩左上角一块
   → 画 64×64 位图不设 dpr，让 QIcon 缩到 17px
4. TableWidget 的单元格宽高在渲染前拿到的是旧值，操作列须在 strip 的 `resizeEvent` / `showEvent` 里再对位一次

### 1 “离开即存”失灵的根因

  FocusOut 只作为补充；下拉/日历弹窗开着时每 150ms 重试（上限 25 次）

- `refresh()` / 插入行 / 切行编辑 / 右键菜单 / 列头菜单 / 导出 / 撤消恢复，统统先 `_settle_edit()`

### 3 撤消/恢复上移到界面级（照 WPS）

  主窗口按当前页刷新按钮亮灰

**门店节点结构（顺序即用户口径）**

（`main_window.STORE_REPORTS` / `STORE_CLASSES`；`ui/pages/store_reports.py` 新增两页）

**口径（参照 store_manage_system 门店报表，落到羊链路）**
- 统一取数 `calc.store_flow_rows(store, store_id, day)`，按商品归并、一级明细取商品档案类别
  （白条 / 分割品 / 副产品，档案没有的归「未分类」）
- 上日结余 = 截至前一日累计入库 − 累计销售（金额按累计入库加权均价）
- 当日入库 = 当日 store_in；当日结余：当天有盘点取实盘，没盘点取账面（open+in−sale）
- 当日出库 = 上日结余 + 当日入库 − 当日结余（倒算，含盘亏/盘盈）
- 当日销售 = 当日 store_sale 应收；当日损益 = 销售 − 出库
- 损益报表：一 产出/收入、二 投入/成本、三 产投/损益、六 盈利指标（编号沿用日报表，一/二/三/六），
  行结构由 `core/services/store_report.py` 统一给出，页面与 Excel 共用
- 进销存列名把参考项目的「当日采购」改成「**当日入库**」，与门店入库台账用词一致
- 门店报表日期只认页面抬头「业务日期」（单日），筛选条不再放日期控件
