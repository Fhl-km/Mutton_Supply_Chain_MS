# 2026-11-20　羊供应链管理系统（Mutton_Supply_Chain_MS）

## 任务
按 `账表记录-羊.xlsx` 七张空账表，用 PySide6 + src 结构开发「羊供应链管理系统」，
分两个模块：活羊采购 & 屠宰（暂养出入库 / 养殖 / 屠宰 / 屠宰出库）、
门店管理（门店节点「关一店」下设入库盘点 / 销售 / 库存盘点三张台账）。
设计思路参照 `E:\python\store_manage_system`（深蓝侧栏 + 金色点缀、页签式多页、
行内录入台账、JSON 账套、派生数字现算）。

## 关键口径（已写进代码与「填写说明」）
- 暂养台账：入库金额 = kg × 单价；出库金额按**批次累计入库加权平均单价**；结存 = 累计入 − 累计出
- 养殖：期初接上一行期末，批次首行取批次档案入栏只数；期末 = 期初 − 出栏
- 屠宰：出肉率 = 产出 kg ÷ 领入毛重；领用成本 = 毛重 × 批次加权均价；单位成本 = 成本 ÷ 产出 kg
- 门店：账面库存 = 入库 − 销售（按 门店 × 批次 × 商品）；盘点差异 = 实盘 − 账面
- 毛利（简化）：(门店销售 + 屠宰直销) − 已售成本，调拨不计收入；成本按批次加权平均
- 屠宰产出「只数」按类别重复计算，**横向不可累加**，单据表改显「产出项数」，导出合计只汇总 kg 与金额

## 设计取舍
- 六张平铺台账走行内录入（`pages/base_ledger.py` 统一骨架），屠宰记录是「单据 + 分录」用对话框
- 派生数字一律不落库（`core/calc.py` 现算），改原始行即全链联动
- 门店台账锁定 store_id，避免单据串店；门店节点由门店档案驱动（加店即加节点）
- 屠宰出库「门店调拨」可一键转门店入库，靠 `link_id` 保证幂等
- 门店盘点支持「按账面生成」草稿行
- 列多的台账（暂养 17 列）操作列可能滑出屏幕，补了右键菜单（编辑 / 删除本行）

3. 屠宰单对话框 `ctx.batch_options(self.conn, …)` 多传参数会崩 → 已修（重要：这是入口级 bug）
